Afegir alumnes:
curl -X POST http://localhost:8080/api/customer ^
-H "Content-Type: application/json" ^
-d "{\"name\":\"Pikachu\",\"description\":\"\",\"course\":\"ASIX1\",\"age\":5,\"password\":\"pikachu123\"}"

Mostrar els alumnes:
curl -X GET http://localhost:8080/api/customer

Mostrar alumne mintjançant el ID:
curl -X GET http://localhost:8080/api/customer/2

Actualitzar dades d'un alumne per ID:
curl -X PUT "http://localhost:8080/api/customer/1" ^
-H "Content-Type: application/json" ^
-d "{\"name\":\"Commander Shepard\",\"description\":\"prova\",\"course\":\"DAM1\",\"age\":29,\"password\":\"shepard123\"}"

Actualitzar dades parcialment d'un alumne per ID:
curl -X PATCH "http://localhost:8080/api/customer/2/age?age=51"

Eliminar alumne per id:
curl -X DELETE http://localhost:8080/api/customer/2


Per mostrar el JSON al navegador:
http://localhost:8080/api/customer

http://localhost:8080/api/customer/1

Per pujar imatges dels alumnes:
curl -X POST -F "imageFile=@C:/Users/Nuria/Desktop/Fotos_Alumnes/Gengar.jpg" http://localhost:8080/api/customer/1/image
curl -X POST -F "imageFile=@C:/Users/Nuria/Desktop/Fotos_Alumnes/Luigi.jpg" http://localhost:8080/api/customer/2/image
curl -X POST -F "imageFile=@C:/Users/Nuria/Desktop/Fotos_Alumnes/Ditto.jpg" http://localhost:8080/api/customer/3/image

Inserir 10 alumnes amb .csv:
curl -X POST -F "csvFile=@C:/Users/Nuria/Desktop/10alumnes.csv" http://localhost:8080/api/customer/upload-csv

Inserir 3 alumnes amb .json:
curl -X POST -F "jsonFile=@C:/Users/Nuria/Desktop/3alumnes.json" http://localhost:8080/api/customer/upload-json
